# Last Wick

Last Wick is a small horror survival game that I created using HTML, CSS, and JavaScript. The main idea behind this game is to explore a dark maze, collect five candle stubs, and find the exit while avoiding the creature that is hunting the player.

I wanted to make a simple horror game that creates tension through darkness, limited visibility, sound, and an enemy that follows the player.

## About the Game

The game takes place inside a dark, randomly generated maze. Every time a new game starts, the maze is generated again, so the layout is different.

The player has to find all five candle stubs hidden throughout the maze. Once all five candles are collected, the exit becomes available. However, there is a creature inside the maze that can detect and chase the player.

The main challenge is to collect everything and reach the exit without getting caught.

## Features

- Randomly generated maze for each new game.
- Dark environment with a limited lantern light effect.
- Five candle stubs that need to be collected.
- An enemy that can patrol and chase the player.
- Lantern oil that can be collected to increase the light.
- Stamina system that limits how long the player can run.
- Sound effects and background horror ambience.
- Screen shaking and a red visual effect when the enemy gets close.
- A jumpscare when the player is caught.
- Win and game over screens.

## Controls

W, A, S, D or Arrow Keys: Move the player.

Shift: Run.

Enter: Start the game or play again.

## How to Play

1. Start the game by pressing Enter.
2. Explore the maze and search for the five candle stubs.
3. Collect lantern oil whenever you find it.
4. Be careful while running because the enemy can detect movement from a greater distance.
5. Avoid the creature and keep an eye on your stamina and lantern oil.
6. Collect all five candles to unlock the exit.
7. Reach the exit to escape and win the game.

If the creature catches you, a jumpscare appears and the game ends. You can press Enter to try again.

## Technologies Used

- HTML for the basic game structure.
- CSS for the page layout and canvas styling.
- JavaScript for the game logic, maze generation, player movement, enemy behaviour, lighting, and sound effects.
- HTML Canvas API for drawing the game and its visual effects.
- Web Audio API for generating the horror ambience and sound effects.

## How to Run

1. Download or clone this project.
2. Open the project folder in VS Code.
3. Open the HTML file in a browser.
4. Press Enter to start playing.

No additional game engine is required.
